# 安全与测试边界

本工具会在用户点击安装时写入选定游戏目录。先退出游戏，并保留原始文件和恢复记录。

配置目录与个人版隔离，未自动导入旧路径。未知 DLL 冲突、被更改的受管二进制、缺失组件会停止操作；这些检查不构成反作弊兼容保证。

本地 EXE/DLL 选择器不是恶意软件扫描器。尤其 Magpie 与任意用户 OptiScaler 包没有统一可信签名保证，应只选择信任的官方或有权提供的来源。

网页使用 WebView2 的默认安全机制，不关闭沙箱，不向网页暴露宿主对象。外部 Magpie 由浏览器启动后，停止操作仅向该子进程的窗口发送正常退出请求；不会结束其他 Magpie 进程。

报告问题时请先删除日志中的用户名、本地路径、账号和游戏登录标识。不要上传 DLL、模型或整个 AppData。
