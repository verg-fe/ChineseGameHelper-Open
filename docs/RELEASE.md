# 发布清单

仅发布 `package.ps1` 产生的源码 ZIP 和便携 ZIP。不要上传个人试验版 EXE、旧源码目录内的 ZIP、AppData、模型、游戏文件、截图日志或录屏。

源码包：仅文本源码、构建/测试/打包脚本、说明和许可证。

便携包：助手 EXE、WebView2 SDK 的两个托管 DLL、x86/x64 loader、Microsoft LICENSE/NOTICE、本项目文档。

本项目不包含 WebView2 Runtime。可再分发 SDK 不等于整个浏览器运行时开源。

发布之前运行全部测试和包内清单检查。测试必须不依赖旧助手缓存或个人组件目录。若新增组件或新版本，重新核对许可、源地址、哈希、构建来源及相应源码义务。

当前源码没有迁移旧版安装记录的功能；在旧版恢复后重新安装，避免丢失原始备份关系。

支持的桥接版本使用固定哈希识别。不要为了兼容未知包而取消校验，更不要将私有运行库或修改件补进源码包。
