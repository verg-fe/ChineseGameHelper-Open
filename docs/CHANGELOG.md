# 中文游戏助手 · 开源版 v0.2.0

本次新增所有游戏共用的四档输入分辨率设置，以及游戏日志中的实际分辨率核对。

## 新增功能

- **四档输入分辨率**：质量、平衡、性能、超级性能。读取所选显示器的物理像素，支持多屏切换，避免 Windows 显示缩放影响计算。
- **按游戏保存**：每个游戏独立保存档位；尚未安装组件时只保存偏好，以后安装受支持的桥接或组合时沿用，不自动安装插件。
- **日志辅助核对**：显示最近日志的更新时间、实际输出和神经输入尺寸、接受的处理次数、抽样帧结果。游戏窗口尺寸与屏幕不同会提示；没有尺寸证据时明确显示尚未验证。
- **保留备份与恢复**：修改受管配置前备份，更新恢复记录；保留开启状态、处理次数、同步设置、独立 NR 缩放和帧生成配置。

## 使用方式

完整解压 `ChineseGameHelper-Open-portable.zip`，运行 `中文游戏助手-开源版.exe`。

**选游戏 → 输入分辨率 / 日志 → 选屏幕与档位 → 保存 → 重启游戏 → 刷新日志核对。**

ReShade 桥接修改神经网络输入比例，不降低游戏自身的渲染分辨率；OptiScaler 修改升频输入比例。Daniel 独立版保存偏好并提示在游戏内选择对应 FSR 档位，不强写未知设置。实际尺寸由游戏输出和组件支持情况决定。

## 下载与发布范围

- `ChineseGameHelper-Open-portable.zip`：便携版 EXE、WebView2 SDK 文件及文档；浏览器需系统安装 WebView2 Runtime。
- `ChineseGameHelper-Open-source.zip`：完整 MIT 管理器源码与构建脚本。
- `SHA256SUMS.txt`：下载文件校验值。

此 Release 不包含第三方神经运行库、模型权重、游戏文件或个人试验版补丁。外部组件入口与数据隔离方式保持原版开源设计。

已完成开源版编译和打包。本次没有重复运行发布包自检；源码附带 `--resolution-self-test` 和测试脚本。配置保存不等于所有游戏都兼容，实际画质、帧率与稳定性需游戏内验证。
